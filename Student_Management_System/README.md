Student Management System

Project Description

This Python project manages student records using a simple console-based application.

Features

- Add student details
- View all students
- Search students by ID
- Update student details
- Delete student records
- Save student data in a JSON file
- Validate student marks and input
- Handle file errors

Technologies Used

- Python 3.15
- JSON
- Python IDLE

How to Run

1. Keep "student_management.py" in the project folder.
2. Open the file in Python IDLE.
3. Press F5 to run the program.
4. Choose an option from the menu.
5. Student data is saved in "students.json".
