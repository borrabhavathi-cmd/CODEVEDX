# Password Generator & Strength Checker

## Project Description
This Python project checks password strength
and generates a secure random password.

## Features
- Password strength checking
- Secure password generation
- Random password creation

## Technologies Used
- Python 3.15
- Python IDLE

## How to Run
1. Download password_checker.py
2. Open it in Python IDLE.
3. Run the program using F5.
4. Enter a password to check its strength.
5. Choose yes to generate a password.
