PASSWORD GENERATOR & STRENGTH CHECKER

Project: Python Programming Internship

Description:
This project generates secure passwords and checks
password strength using Python.

Features:
1. Password strength checking.
2. Weak, Medium, and Strong ratings.
3. Secure password generation.
4. Uses uppercase, lowercase, numbers, and symbols.

Technology Used:
Python 3.15

How to Run:
1. Open password_checker.py in Python IDLE.
2. Press F5.
3. Enter a sample password.
4. Choose yes to generate a password.
