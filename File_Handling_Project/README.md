File Handling & Data Processing System

Project Description

This Python project reads student marks from a CSV file, processes the data, sorts students by marks, calculates the average, and saves the results to a new CSV file.

Features

- Reads student data from CSV files
- Sorts students by marks in descending order
- Filters students scoring 75 or above
- Calculates average marks
- Saves processed data to a new CSV file
- Handles FileNotFoundError and PermissionError
- Validates student names and marks

Technologies Used

- Python 3.15
- CSV file handling
- Python IDLE

How to Run

1. Keep "students.csv" and "file_processing.py" in the same folder.
2. Open "file_processing.py" in Python IDLE.
3. Press F5 to run the program.
4. View the processed results in the output.
5. Open "processed_students.csv" to see the saved data.

Output

The program displays sorted student marks, average marks, and students scoring 75 or above.
